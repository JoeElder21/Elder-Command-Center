# Communication Standards (DRAFT templates)

> Every message below is a DRAFT. Joe approves before anything is sent. Never add titles or letters such as PE, PLA, "engineer" or "landscape architect" to a signature.

## Client Communication

- Professional, confident, proactive
- Lead with progress and solutions, not problems
- Provide options with clear recommendations
- Include timeline expectations
- Never surprise the client — flag issues early
- Use "we" language ("We recommend...", "Our analysis shows...")
- Close with specific next steps and who owns them

**Template:**
```
DRAFT — approval required before sending

Subject: [Project Name] — [Topic] Update

[Client Name],

[1-2 sentence summary of status or finding]

[Key details — use bullets or table]

Our recommendation: [specific action with rationale]

Next steps:
1. [Action] — [Owner] — [Timeline]
2. [Action] — [Owner] — [Timeline]

Please let me know if you have questions or would like to discuss.

Joe Elder
Elder Land Design
```

## Contractor Communication

- Direct, technical, action-oriented
- Reference specific plan sheets, details, and specifications
- Include dimensions, elevations, and material callouts
- No ambiguity — if it can be misread, it will be
- Document everything in writing
- Set clear deadlines and expectations

**Template:**
```
DRAFT — approval required before sending

Subject: [Project Name] — [RFI/Directive/Clarification] #[Number]

[Contractor Name],

Regarding [specific item]:

[Clear technical direction with references to plan sheets and details]

Required action:
- [Specific task with dimensions/specifications]

Deadline: [Date]

Confirm receipt and acknowledgment.

Joe Elder
Elder Land Design
```

## Agency Communication

- Formal, reference-heavy, compliant
- Cite specific code sections, ordinance numbers, and regulation references
- Include application numbers and project identifiers
- Follow agency-specific submission requirements
- Never argue — present facts and request guidance
- Be respectful of review timelines
- Follow up in writing after verbal conversations

**Template:**
```
DRAFT — approval required before sending

Subject: [Application/Project Number] — [Project Name] — [Topic]

[Reviewer Name / Department],

Per [code section/ordinance/regulation], we are submitting [document/request] for
[project name] located at [address/parcel].

[Specific request or response to review comments, with code citations]

Enclosed: [List of attachments]

Please contact me with any questions.

Joe Elder
Elder Land Design
[Phone] | [Email]
```

## Internal Communication

- Efficient, strategic, no unnecessary formality
- Bullet points preferred
- Decision-ready format: Situation → Options → Recommendation
- Flag blockers immediately
- Include financial implications when relevant

## Client Relationship Tiers

| Tier | Definition | Response Standard |
|------|-----------|-------------------|
| **High Value** | Repeat clients, large projects, strategic relationships | Same-day response, proactive updates, white-glove service |
| **Active** | Current project clients | 24-hour response, regular progress updates |
| **Opportunity** | Prospective clients, referral sources | 48-hour response, professional follow-up |
