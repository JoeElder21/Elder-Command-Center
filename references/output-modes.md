# Output Modes, Quality Tiers, Design Standards and Daily Planning

Default output is answer-first. Use a mode below only when Joe names it or the deliverable calls for it.

## Output Modes

| Mode | Use Case | Format |
|------|----------|--------|
| **Executive Summary** | Client presentations, leadership briefings | 1 page max, bullet points, key metrics highlighted |
| **Builder's Plan** | Construction teams, contractors | Action items, dimensions, sequences, no theory |
| **Technical Breakdown** | Engineering review, peer review | Full calculations, code references, methodology |
| **Client-Ready Draft** | Documents going to clients under JEDS letterhead | Polished prose, JEDS brand, professional tone |
| **Founder Strategy Memo** | Joe's internal decision-making | Candid analysis, risks, financial implications, recommendations |
| **Presentation Upgrade** | Pitch decks, public hearings, proposals | Visual-first, key stats, compelling narrative |

Specify the output mode at the start of a request. If not specified, default to Standard Response Framework (Section 4.1).

## Tables Over Paragraphs

For structured data, always use tables:
- Zoning comparisons → table
- Cost estimates → table
- Schedule → table
- Parking calculations → table
- Plant lists → table
- Material specifications → table
- Contact lists → table

Reserve paragraphs for narrative analysis, strategic recommendations, and client-facing prose.

## Output Quality Tiers

| Tier | Depth | Use Case |
|------|-------|----------|
| **Quick Take** | 1-2 paragraphs | Slack message, quick answer, gut check |
| **Standard** | Full framework (Section 4.1) | Most requests, internal analysis |
| **Deep Dive** | Comprehensive with research | Complex zoning issues, technical problems, multi-factor decisions |
| **Production** | Client-ready, branded, formatted | Documents leaving JEDS, fee proposals, reports |

## Design and Presentation Standards

All client-facing documents and presentations must comply with JEDS brand (`references/brand/jeds.md`):
- Headings in Cormorant Garamond, body in Outfit
- Gold (`#D4AF37`) for accent lines, highlights, and key metrics
- Dark Green (`#2D5016`) for headings and primary text elements
- Cream (`#F5F5DC`) for backgrounds and card elements
- Light Green (`#7CB342`) for secondary accents, status indicators, and callouts
- Clean layouts with generous white space
- No clip art, no stock imagery without approval
- Maps and diagrams labeled clearly with north arrow, scale, and legend

## Daily Planning Format

When Joe asks for daily planning or schedule support:

```
## [Date] — Daily Operations

### Critical Path (must complete today)
1. [Task] — [Project] — [Deadline/Context]
2. [Task] — [Project] — [Deadline/Context]

### High Priority (complete if possible)
1. [Task] — [Project]
2. [Task] — [Project]

### Active Items (move forward)
1. [Task] — [Project]

### Waiting On
- [Item] — waiting on [person/agency] since [date]

### Tomorrow Preview
- [Key item for tomorrow]
```
