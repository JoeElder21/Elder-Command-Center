## 1. Governing Standards and Authorities

### 1.1 Applicable Standards

| Standard | Full Title | Application |
|----------|-----------|-------------|
| 2010 ADA Standards for Accessible Design | Dept. of Justice, 28 CFR Part 36 | Buildings, facilities, sites — private and public |
| ABA Accessibility Standards | GSA, DoD, USPS, HUD facilities | Federally funded facilities |
| PROWAG | Public Rights-of-Way Accessibility Guidelines | Public sidewalks, crosswalks, shared-use paths |
| AASHTO Guide for the Planning, Design, and Operation of Pedestrian Facilities | Pedestrian facility design | State and local roadways |
| Kentucky Building Code | KBC — based on IBC with amendments | Kentucky-specific building accessibility |
| ANSI A117.1 | Accessible and Usable Buildings and Facilities | Referenced by building codes |
| MUTCD | Manual on Uniform Traffic Control Devices | Accessible pedestrian signals, crosswalks |

### 1.2 When Each Standard Applies

| Project Type | Primary Standard | Notes |
|-------------|-----------------|-------|
| Private commercial development | 2010 ADA Standards | Parking, accessible routes, building entries |
| Public facility (state/local) | 2010 ADA Standards + ABA (if federally funded) | Title II compliance |
| Public right-of-way (sidewalks, crosswalks) | PROWAG | Applies to new construction and alterations |
| Residential (multi-family 4+ units) | Fair Housing Act + ADA (common areas) | FHA has separate requirements |
| Kentucky state-funded projects | KBC + ADA | KBC may have additional requirements |

**Key Principle:** When standards conflict, apply the more stringent requirement. ADA is a federal civil rights law — compliance is mandatory, not optional.

## 2. Accessible Routes

### 2.1 General Requirements

| Parameter | Requirement | Reference |
|-----------|------------|-----------|
| Minimum Clear Width | 36 inches (44 inches preferred) | ADA 403.5.1 |
| Passing Space | 60 inches x 60 inches at intervals of 200 ft max | ADA 403.5.3 |
| Running Slope (maximum) | 5.0% (1:20) — exceeding this triggers ramp requirements | ADA 403.3 |
| Cross Slope (maximum) | 2.0% (1:50) | ADA 403.3 |
| Surface | Firm, stable, and slip-resistant | ADA 302.1 |
| Changes in Level | 0-1/4 inch — vertical; 1/4-1/2 inch — beveled 1:2; > 1/2 inch — ramp or elevator | ADA 303 |
| Protruding Objects | Objects on walls: 4 inches max projection (27-80 inches above floor) | ADA 307 |
| Vertical Clearance | 80 inches minimum headroom | ADA 307.4 |
| Grate Openings | 1/2 inch max in direction of travel | ADA 302.3 |

### 2.2 Where Accessible Routes Are Required

An accessible route must connect all of the following:

- Public transportation stops, accessible parking, and passenger loading zones
- Building entrances (at least one accessible entrance per building)
- Public sidewalks and rights-of-way adjacent to the site
- All accessible building spaces and elements
- Between buildings on a common site

**Route of Travel:** If an alteration affects a primary function area, an accessible path of travel must be provided to the altered area. The cost of providing the accessible path of travel is not required to exceed 20% of the cost of the alteration [VERIFY current disproportionate cost threshold].

### 2.3 Accessible Route Surfaces

| Surface Type | Accessible? | Notes |
|-------------|-------------|-------|
| Concrete (broom finish) | Yes | Standard accessible surface |
| Asphalt (smooth) | Yes | Acceptable; maintain smooth surface |
| Concrete unit pavers (tight joints) | Yes | Joint width <= 1/2 inch; firm setting bed |
| Brick pavers (tight joints) | Yes | Smooth-faced; joint width <= 1/2 inch |
| Compacted crushed stone (firm) | Conditional | Must meet firm/stable/slip-resistant standard; difficult to maintain |
| Loose gravel | No | Not firm or stable |
| Sand | No | Not firm or stable |
| Mulch | No | Not firm or stable |
| Wood decking | Yes | Gap width 1/2 inch max; boards perpendicular to travel |
| Turf / grass | No | Not firm or stable |

## 3. Ramp Design

### 3.1 When a Ramp Is Required

A ramp is required wherever an accessible route has a running slope exceeding 5.0% (1:20). A ramp slope exceeding 8.33% (1:12) is not permitted.

### 3.2 Ramp Design Parameters

| Parameter | Requirement | Reference |
|-----------|------------|-----------|
| Maximum Running Slope | 8.33% (1:12) | ADA 405.2 |
| Maximum Cross Slope | 2.0% (1:50) | ADA 405.3 |
| Minimum Clear Width | 36 inches between handrails | ADA 405.5 |
| Maximum Rise per Run | 30 inches (then a landing is required) | ADA 405.6 |
| Maximum Horizontal Run | 30 ft per segment (at 1:12 slope) | Derived from 405.6 |

### 3.3 Ramp Landings

| Parameter | Requirement | Reference |
|-----------|------------|-----------|
| Top Landing | 60 inches minimum length, full width of ramp | ADA 405.7 |
| Bottom Landing | 60 inches minimum length, full width of ramp | ADA 405.7 |
| Intermediate Landings | 60 inches minimum length at every 30-inch rise | ADA 405.7 |
| Landing at Direction Change | 60 inches x 60 inches minimum | ADA 405.7.4 |
| Landing Slope | 2.0% maximum in any direction | ADA 405.7.1 |
| Door Landings | 60 inches minimum perpendicular to door; door swing must not reduce landing | ADA 404 |

### 3.4 Handrails

| Parameter | Requirement | Reference |
|-----------|------------|-----------|
| When Required | Both sides of ramps with rise > 6 inches | ADA 405.8 |
| Height | 34-38 inches above ramp surface | ADA 505.4 |
| Grip Size (circular) | 1.25-2.0 inches outside diameter | ADA 505.7.1 |
| Top Extension | 12 inches minimum beyond top of ramp, parallel to ground | ADA 505.10.1 |
| Bottom Extension | 12 inches minimum beyond bottom of ramp, at ramp slope + 12 inches horizontal | ADA 505.10.2 |
| Clearance from Wall | 1.5 inches minimum | ADA 505.5 |
| Surface | Smooth, continuous, no sharp edges | ADA 505.6 |
| Graspability | Must be graspable along entire length | ADA 505.7 |
| Edge Protection | Required — curb (4 inches min), rail, or wall | ADA 405.9 |

## 4. Detectable Warning Surfaces

### 4.1 Where Required

| Location | Required? | Reference |
|----------|-----------|-----------|
| Curb ramps at street crossings | Yes | ADA 705, PROWAG |
| Raised pedestrian crossings | Yes | PROWAG |
| Transit platform edges | Yes | ADA 705.1 |
| Reflecting pools and other hazards | Yes | ADA 705.1 |
| Top of stairs at hazardous vehicular areas | PROWAG context | PROWAG |
| Building entries from parking lots | No (unless adjacent to vehicular way) | ADA context-dependent |

### 4.2 Design Specifications

| Parameter | Requirement | Reference |
|-----------|------------|-----------|
| Pattern | Truncated dome | ADA 705.1 |
| Dome Diameter (base) | 0.9-1.4 inches | ADA 705.1 |
| Dome Diameter (top) | 50-65% of base diameter | ADA 705.1 |
| Dome Height | 0.2 inches nominal | ADA 705.1 |
| Dome Spacing (center-to-center) | 1.6-2.4 inches | ADA 705.1 |
| Alignment | Square grid or radial pattern | ADA 705.1 |
| Width (perpendicular to curb) | 24 inches in direction of travel | ADA 705.1 |
| Full Width of Ramp | Must extend the full width of the curb ramp | PROWAG |
| Color Contrast | Visual contrast with adjacent surface (typically yellow on gray concrete) | ADA 705.1 |
| Material | Cast-in-place, surface-applied, or preformed panels; must be durable and slip-resistant | Per specification |

### 4.3 Placement at Curb Ramps

- Detectable warnings are placed at the back of the curb line or where the ramp meets the street
- Must extend the full width of the curb ramp (excluding flares)
- 24 inches in the direction of pedestrian travel
- For perpendicular curb ramps: placed at the bottom of the ramp
- For parallel curb ramps: placed at the transition from the landing to the crosswalk
- For blended transitions: placed at the back of curb across the full width of the pedestrian crossing

## 5. Accessible Parking

### 5.1 Number of Accessible Spaces Required

| Total Parking Spaces | Minimum Accessible Spaces | Van-Accessible Spaces |
|---------------------|--------------------------|----------------------|
| 1-25 | 1 | 1 (of the accessible spaces) |
| 26-50 | 2 | 1 |
| 51-75 | 3 | 1 |
| 76-100 | 4 | 1 |
| 101-150 | 5 | 1 |
| 151-200 | 6 | 1 |
| 201-300 | 7 | 2 |
| 301-400 | 8 | 2 |
| 401-500 | 9 | 2 |
| 501-1000 | 2% of total | 1 per 6 accessible (min) |
| > 1000 | 20 + 1 per 100 over 1000 | 1 per 6 accessible (min) |

Source: ADA Standards Table 208.2 [VERIFY].

**Van-Accessible Requirement:** At least 1 in every 6 accessible spaces (rounded up) must be van-accessible. Minimum 1 van-accessible space at every parking facility.

### 5.2 Accessible Parking Dimensions

| Parameter | Standard Accessible | Van-Accessible | Reference |
|-----------|-------------------|----------------|-----------|
| Stall Width | 96 inches (8 ft) | 132 inches (11 ft) — OR 96 inches with 96-inch aisle | ADA 502.2 |
| Access Aisle Width | 60 inches (5 ft) | 60 inches (if stall is 132 in) — OR 96 inches (if stall is 96 in) | ADA 502.3 |
| Combined Width (stall + aisle) | 156 inches (13 ft) | 192 inches (16 ft) | Calculated |
| Stall Length | 18 ft minimum (20 ft for van spaces in some jurisdictions) | 18-20 ft [VERIFY local] | ADA 502.2 |
| Surface Slope | 2.0% maximum in any direction | 2.0% maximum | ADA 502.4 |

### 5.3 Accessible Parking Layout Requirements

| Requirement | Detail | Reference |
|-------------|--------|-----------|
| Location | Closest accessible route to building entrance | ADA 208.3.1 |
| Surface | Firm, stable, slip-resistant; no ponding | ADA 502.4 |
| Access Aisle | Must be marked (striped); may be shared between two accessible spaces | ADA 502.3 |
| Vertical Clearance (van) | 98 inches (8 ft 2 in) minimum at space, access aisle, and route to exit | ADA 502.5 |
| Signage | International Symbol of Accessibility; mounted 60 inches min above grade | ADA 502.6 |
| Van Signage | "Van Accessible" below ISA sign | ADA 502.6 |
| Connection to Route | Access aisle connects directly to accessible route; no curb or step | ADA 502.3.4 |

### 5.4 Accessible Parking — Common Design Errors

| Error | Problem | Solution |
|-------|---------|----------|
| Access aisle behind parked cars | Pedestrians in travel lane | Place access aisle between spaces or adjacent to curb |
| Excessive cross slope | Wheelchair instability | Grade to 2.0% max in all directions |
| Curb between aisle and sidewalk | Wheelchair barrier | Provide flush transition or curb ramp at aisle |
| No van clearance | Van cannot park | Verify 98-inch vertical clearance on entire path |
| Spaces too far from entrance | Excessive travel distance | Locate at closest point on accessible route |
| Ponding in accessible spaces | Wheelchair immobility, ice hazard | Grade for positive drainage at 1-2% |

## 6. Curb Ramp Design

### 6.1 Curb Ramp Types

| Type | Description | Application |
|------|-------------|-------------|
| Perpendicular | Ramp runs perpendicular to curb face | Standard at intersections with space |
| Parallel | Ramp runs parallel to curb with mid-landing turn | Narrow sidewalks where perpendicular not feasible |
| Combination | Perpendicular with parallel components | Corner conditions with limited space |
| Blended Transition | Sidewalk gradually descends to street level | Wide sidewalks, shared-use paths |
| Diagonal (not preferred) | Single ramp at corner apex pointing diagonally | Not recommended — directs user into intersection center |

### 6.2 Curb Ramp Design Parameters

| Parameter | Requirement | Reference |
|-----------|------------|-----------|
| Maximum Running Slope | 8.33% (1:12) | ADA 406.1 |
| Maximum Cross Slope | 2.0% (1:50) | ADA 406.1 |
| Minimum Width | 48 inches (exclusive of flares) | ADA 406.1, PROWAG |
| Flare Slope (maximum) | 10.0% (1:10) where pedestrians must cross flare | ADA 406.3 |
| Landing at Top | 48 inches x 48 inches minimum at 2% max slope | ADA 406.4 |
| Detectable Warning | Required — 24 inches deep, full width | ADA 705 |
| Counter Slope (gutter) | 5.0% maximum (algebraic difference with ramp <= 13.33%) | PROWAG R304.5.3 [VERIFY] |
| Grade Break | No abrupt grade breaks at top or bottom; tangent transitions | ADA / PROWAG |
| Returned Curb | If flares are not provided, returned curb with 48-inch clear space parallel to curb | ADA 406.3 |

### 6.3 Curb Ramp Placement at Intersections

- **Two ramps per corner** (one per crosswalk) are preferred over a single diagonal ramp
- Each ramp must be aligned with the direction of the crosswalk it serves
- Ramp must not direct pedestrians into the center of the intersection
- Crosswalk markings should align with the curb ramp
- Where medians or pedestrian refuge islands are present, provide cut-through at crosswalk level (accessible route through island)

## 7. Level Landings at Doors

### 7.1 Maneuvering Clearance at Doors

| Approach Direction | Door Type | Clearance Beyond Latch (Pull Side) | Clearance Beyond Latch (Push Side) | Depth |
|-------------------|-----------|-----------------------------------|------------------------------------|-------|
| Front Approach | Swing (pull) | 18 inches | 0 inches | 60 inches |
| Front Approach | Swing (push) | 0 inches | 0 inches | 48 inches |
| Hinge Approach | Swing (pull) | 36 inches | N/A | 60 inches |
| Hinge Approach | Swing (push) | N/A | 22 inches | 48 inches (42 w/closer) |
| Latch Approach | Swing (pull) | 24 inches | N/A | 60 inches (54 w/closer) |
| Latch Approach | Swing (push) | 24 inches | N/A | 48 inches (44 w/closer) |
| Sliding | Any | 24 inches | N/A | 48 inches |

Source: ADA Standards Table 404.2.4 [VERIFY].

### 7.2 Level Landing at Building Entrances

| Parameter | Requirement |
|-----------|------------|
| Minimum Size | 60 inches x 60 inches at primary entrance |
| Slope | 2.0% maximum in any direction |
| Surface | Concrete or equivalent firm surface; no grates in landing |
| Drainage | Must drain without ponding; verify grading directs water away from door |
| Threshold Height | 1/2 inch maximum (3/4 inch for sliding doors) | 
| Door Hardware | Operable with one hand, without tight grasping, pinching, or twisting of the wrist |
| Door Closer | 5-second minimum from 90 degrees open to 12 degrees from latch |
| Opening Force | 5 lbf maximum for interior doors; exterior and fire doors per code |

**Site Design Note:** The landscape architect / civil engineer is responsible for the accessible route and grading to building entrances. Coordinate with the architect to ensure the landing elevation, slope, and drainage are achievable with the proposed grading plan. The 2% maximum landing slope is frequently violated when grading is not carefully coordinated with floor elevations.

## 8. Stairs (Exterior)

### 8.1 Stair Design for Site Work

| Parameter | Requirement | Reference |
|-----------|------------|-----------|
| Riser Height | 4-7 inches (uniform throughout flight) | ADA 504.2 |
| Tread Depth | 11 inches minimum | ADA 504.3 |
| Nosing | 1.5 inches max projection; radius 1/2 inch max or beveled | ADA 504.5 |
| Riser Profile | Solid (no open risers) | ADA 504.4 |
| Handrails | Both sides, 34-38 inches above nosing | ADA 504.6 |
| Top Extension | 12 inches horizontal beyond top riser | ADA 505.10.2 |
| Bottom Extension | One tread depth beyond bottom riser | ADA 505.10.3 |

**Note:** Stairs are never a substitute for an accessible route. If stairs are provided, an accessible route (ramp, elevator, or grade-level path) must also be provided.

## 9. Sidewalks and Pedestrian Paths

### 9.1 Sidewalk Design Standards

| Parameter | ADA Minimum | Recommended | Notes |
|-----------|------------|-------------|-------|
| Width | 36 inches | 60 inches | 60 inches allows two wheelchairs to pass |
| Running Slope | 5.0% max (follows grade of adjacent road in PROWAG) | < 5.0% | If > 5%, ramp requirements apply |
| Cross Slope | 2.0% max | 1.5% | Design to 1.5% to allow construction tolerance |
| Vertical Clearance | 80 inches | 84 inches | Tree branches, signs, awnings |
| Surface | Firm, stable, slip-resistant | Broom-finish concrete | No loose aggregate or uneven surfaces |
| Joint Width | 1/2 inch max | 1/4 inch | Control and expansion joints |
| Changes in Level | 1/4 inch vertical, 1/2 inch beveled | Flush | Minimize all level changes |
| Cross-Drain Grate Openings | 1/2 inch max in direction of travel | Perpendicular to travel | ADA-compliant grates required |
| Obstructions | 32-inch min clear width past obstruction | 36 inches | Poles, hydrants, furniture |

### 9.2 Cross Slope — Design Tolerance

**Critical Design Note:** The 2.0% maximum cross slope is an absolute maximum, not a target. Design to 1.5% to allow for construction tolerance. If designed at exactly 2.0%, construction tolerances will likely result in some areas exceeding 2.0% and violating ADA.

| Design Cross Slope | Expected Constructed Range | ADA Compliant? |
|--------------------|-----------------------------|----------------|
| 1.0% | 0.5-1.5% | Yes |
| 1.5% | 1.0-2.0% | Yes (within tolerance) |
| 2.0% | 1.5-2.5% | Marginal — likely violations |
| 2.5% | 2.0-3.0% | No — violations likely |

## 12. Accessible Route Checklist for Site Design

### 12.1 Plan Review Checklist

- [ ] Accessible route identified from public sidewalk / right-of-way to building entrance
- [ ] Accessible route identified from accessible parking to building entrance
- [ ] Accessible route identified between all buildings on site
- [ ] Running slope does not exceed 5.0% (or ramps provided where it does)
- [ ] Cross slope does not exceed 2.0% (designed to 1.5% for tolerance)
- [ ] Minimum 36-inch clear width maintained (44 inches preferred)
- [ ] Passing spaces (60 x 60 inches) provided every 200 ft where width < 60 inches
- [ ] Level landings at building entrances (60 x 60 inches, 2.0% max slope)
- [ ] Curb ramps at all pedestrian street crossings with detectable warnings
- [ ] No abrupt grade changes > 1/4 inch without treatment
- [ ] Surface is firm, stable, and slip-resistant throughout
- [ ] Grate openings do not exceed 1/2 inch in direction of travel
- [ ] Accessible parking count meets ADA table (including van-accessible)
- [ ] Accessible parking slopes do not exceed 2.0% in any direction
- [ ] Accessible parking connected to accessible route without curbs/steps
- [ ] Van-accessible spaces have 98-inch vertical clearance
- [ ] Ramps have handrails on both sides if rise > 6 inches
- [ ] Ramp landings meet minimum size requirements (60 inches)
- [ ] Ramp slope does not exceed 8.33% (1:12)
- [ ] Detectable warnings at all curb ramps and hazardous vehicular areas

### 12.2 Grading Plan Coordination

| Check | Action |
|-------|--------|
| Building FFE vs. parking lot elevation | Verify accessible route grade from parking to entrance <= 5% |
| Sidewalk cross slope at driveway crossings | Verify cross slope does not exceed 2% across driveway aprons |
| Landing elevation at entrance doors | Coordinate with architect; verify grading achieves 2% max at landing |
| ADA ramp location | Determine ramp alignment and length based on elevation difference |
| Accessible parking grading | Grade accessible spaces and aisles to 2% max; verify drainage |
| Curb ramp location and grade | Set curb ramp grades on grading plan; verify counter-slope at gutter |

## Verification Notes

- All values in this reference require verification against the current editions of cited standards.
- PROWAG was proposed as a final rule; verify its current adoption status and applicability in Kentucky.
- The Kentucky Building Code may include amendments to national accessibility standards. Always check KBC for state-specific requirements.
- Local jurisdictions may have accessibility requirements that exceed ADA minimums (e.g., wider sidewalks, additional accessible parking).
- Construction tolerances are critical for ADA compliance. Design slopes conservatively (e.g., 1.5% cross slope to stay within the 2.0% maximum after construction).
- ADA compliance is a legal requirement, not a design preference. Non-compliance exposes the project owner to federal civil rights complaints and potential litigation.
- This reference covers site design elements. Building interior accessibility requirements are not included and should be coordinated with the project architect.
