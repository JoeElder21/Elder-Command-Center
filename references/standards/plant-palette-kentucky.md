## 1. Climate and Growing Conditions

### 1.1 USDA Hardiness Zone

| Parameter | Value |
|-----------|-------|
| USDA Zone | 6b |
| Minimum Winter Temperature | -5 to 0 degrees F |
| Average Last Frost (Spring) | April 15-25 [VERIFY local] |
| Average First Frost (Fall) | October 10-20 [VERIFY local] |
| Growing Season | Approximately 170-190 days |
| Annual Precipitation | 44-50 inches |
| Summer High Temperatures | 85-95 degrees F |
| Predominant Soil Types | Silt loam, silty clay loam (Lowell, Faywood, Shelbyville series) |
| Soil pH (typical) | 5.5-7.0 (variable; limestone-derived soils may be alkaline) |

### 1.2 Design Principles for Kentucky Plant Selection

1. **Native and adaptive species preferred** — Reduce irrigation needs, support pollinators, improve long-term survival
2. **Drought tolerance rated** — Kentucky summers include periodic drought; specify species accordingly
3. **Salt tolerance noted** — Important for parking lots, roadway plantings, and urban sites
4. **Mature size drives spacing** — Always design to mature spread, not nursery container size
5. **Right plant, right place** — Match species to soil, moisture, sun exposure, and microclimate
6. **Four-season interest** — Select combinations that provide visual interest year-round
7. **Diversity** — No more than 10% of any single species, 20% of any genus, or 30% of any family in a planting plan

## 12. Planting Specifications

### 12.1 Tree Installation

| Parameter | Specification |
|-----------|--------------|
| Planting Hole Diameter | 2-3 times the root ball diameter |
| Planting Hole Depth | Equal to root ball height (never deeper) |
| Root Flare | Must be visible at or slightly above finished grade |
| Backfill | Native soil (amended only if soil test indicates need) |
| Burlap/Wire Basket | Remove or fold down top 1/3 of burlap; cut and bend wire basket down after setting |
| Container Plants | Score and spread circling roots; butterfly root ball if heavily pot-bound |
| Mulch Ring | 3-inch depth, 3-ft radius minimum; keep mulch 3-6 inches from trunk (no volcano mulching) |
| Staking | Two stakes, flexible ties; remove after one growing season. Required only if tree cannot stand unsupported. |
| Watering | 1 inch per week for first two growing seasons (natural rainfall + supplemental) |
| Wrapping | Trunk wrap on thin-barked species for first 2 winters (remove in spring) |

### 12.2 Shrub Installation

| Parameter | Specification |
|-----------|--------------|
| Planting Hole | 2 times container width; depth equal to root ball |
| Root Flare | At or slightly above finished grade |
| Backfill | Native soil |
| Mulch | 3-inch depth within bed; keep mulch 2-3 inches from stems |
| Spacing | Based on mature spread (typically 2/3 of mature spread for continuous massing) |
| Watering | 1 inch per week for first growing season |

### 12.3 Groundcover and Perennial Installation

| Parameter | Specification |
|-----------|--------------|
| Spacing | Per species mature spread; typically 12-18 inches on center for groundcovers |
| Depth | Crown at grade; do not bury crown |
| Mulch | 2-inch depth between plants; will fill in as plants spread |
| Watering | Regular watering until established (first growing season) |

### 12.4 Mulch Standards

| Parameter | Specification |
|-----------|--------------|
| Type | Shredded hardwood bark mulch (natural, undyed) |
| Depth | 3 inches in tree and shrub beds |
| Keep-Away from Trunks | 3-6 inches from tree trunks; 2-3 inches from shrub stems |
| Volcano Mulching | PROHIBITED — mulch piled against trunk causes rot, disease, and rodent damage |
| Renewal | Top-dress annually to maintain 3-inch depth; do not exceed 4 inches total accumulation |
| Dyed Mulch | Not recommended for professional installations |

### 12.5 Topsoil and Soil Amendment

| Parameter | Specification |

## Verification Notes

- All plant species, sizes, and characteristics should be verified against current nursery availability for the project region.
- Drought tolerance and growth rate ratings are relative and vary by site conditions, soil quality, and maintenance level.
- Salt tolerance ratings are particularly important for parking lot and roadway plantings. Verify for each project context.
- Zone 6b is the baseline; microclimate analysis may support Zone 7a selections in urban heat islands or south-facing protected locations.
- Always verify invasive species status against the current KY-EPPC list, as species are added periodically.
- Spacing and setback requirements vary by local jurisdiction. Always check local street tree ordinances, zoning landscaping requirements, and utility easement restrictions.
- Soil conditions at each project site will influence plant selection. Obtain soil test and review geotechnical report for pH, drainage, and compaction conditions.
- This reference does not replace site-specific planting design by a licensed landscape architect.
