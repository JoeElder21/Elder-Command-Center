# Zoning Compliance Review Prompt

## Purpose

Perform a comprehensive zoning compliance analysis for a proposed development on a specific parcel to identify all dimensional, use, and procedural requirements that must be satisfied. This review determines whether a project can proceed by right, requires variances or conditional use permits, or necessitates a zone change application.

## When to Use

- Before initiating design on a new project to establish the regulatory envelope
- When a client requests confirmation that a proposed use is permitted on a parcel
- Preparing for a Board of Zoning Adjustment (BOZA) or Planning Commission hearing
- Reviewing a competitor's proposal or a project under public notice for a client

## Required Inputs

1. **Parcel ID and jurisdiction** (Louisville Metro, LFUCG, or specific county/city)
2. **Current zoning designation** and any overlay districts
3. **Proposed use(s)** with specific NAICS or local use-table classification
4. **Preliminary site plan** or concept sketch showing building footprint, parking, access
5. **Building dimensions** -- height, gross floor area, number of stories
6. **Applicable zoning ordinance** -- Louisville Metro Land Development Code (LDC), LFUCG Zoning Ordinance, or local equivalent

## Procedure

1. **Identify the Zoning District**: Confirm the zoning classification on the official zoning map. For Louisville Metro, reference the LDC Chapter 2 (zoning district descriptions). For LFUCG, reference Article 8 of the Zoning Ordinance. Document any overlay zones (form districts in Louisville, historic overlays, airport noise contours, or corridor design overlays).
2. **Use Permissibility**: Cross-reference the proposed use against the permitted use table for the zoning district. In Louisville Metro, uses are categorized as Permitted (P), Conditional (C), or Not Permitted (--) in LDC Chapter 4. Document whether each proposed use component is permitted by right or requires a Conditional Use Permit (CUP). If the use is not listed, identify the most analogous use category and note the need for a zoning administrator interpretation.
3. **Dimensional Standards Compliance**: Check the project against all dimensional standards for the district:
   - Minimum lot area and lot width
   - Front, side, and rear yard setbacks (note any build-to lines in form districts)
   - Maximum building height (feet and stories)
   - Maximum lot coverage or impervious surface ratio
   - Floor Area Ratio (FAR) if applicable
   - Minimum open space or landscape surface ratio (LSR)
4. **Parking and Loading**: Calculate required off-street parking using the ordinance table. For Louisville Metro, LDC Chapter 9 Part 1 governs parking. Account for shared parking reductions, proximity to transit (TARC routes in Louisville), bicycle parking requirements, and maximum parking caps if in a form district. Verify loading berth requirements based on gross floor area.
5. **Landscape and Screening**: Identify required landscape buffer yards (LBA) between the proposed use and adjacent properties per the buffer yard table. Determine required street tree plantings, interior parking lot landscaping (typically 1 tree per 10 spaces), and screening requirements for mechanical equipment, dumpsters, and loading areas.
6. **Signage**: Review the sign regulations for the zoning district. Note maximum sign area, height, illumination restrictions, and any prohibited sign types. Flag monument vs. pole sign requirements along specific corridors.
7. **Access and Connectivity**: Confirm compliance with access management standards -- minimum driveway spacing from intersections, shared access requirements, and internal connectivity to adjacent parcels. For Louisville Metro, reference LDC Chapter 6.
8. **Overlay and Special District Requirements**: Apply additional standards from any overlay district. Louisville Metro form districts (traditional neighborhood, suburban marketplace corridor, etc.) impose additional building form and site design standards. Historic preservation overlays require Landmarks Commission or HARB review.
9. **Nonconformity Analysis**: If the site has existing structures or uses, determine nonconforming status under KRS 100.253. Document which elements are legally nonconforming and whether the proposed project will expand, intensify, or eliminate the nonconformity.
10. **Required Approvals Path**: Map the complete approval path: staff-level review only, Category 1/2/3 development plan review (Louisville Metro), BOZA variance or CUP, Planning Commission zone change, or legislative body map amendment.

## Output Format

Produce a compliance matrix table and narrative:
- **Compliance Matrix**: Table with columns for Requirement, Standard, Proposed, Status (Complies / Does Not Comply / Requires Variance)
- **Use Analysis Narrative** (1-2 paragraphs on use permissibility)
- **Dimensional Compliance Summary** (itemized list with calculations)
- **Parking Calculation Sheet** (use categories, rates, required vs. provided)
- **Required Approvals Summary** (hearing body, estimated timeline, application fees)
- **Variance/Waiver Justification Notes** (if applicable, outline findings of fact per KRS 100.243)

## Quality Checks

- All code references must cite the specific chapter, section, and subsection number
- Dimensional calculations must show the math (lot area x coverage ratio = max impervious)
- Parking calculations must use the correct use category, not a generalized rate
- Form district standards must be checked in addition to base zoning district standards
- Nonconforming use analysis must reference the specific KRS 100.253 subsection
- Approval timeline estimates must account for notice requirements (KRS 100.212 public hearing notice)
- Buffer yard determinations must reference both the proposed use and the adjacent use

## Template Reference

- Louisville Metro Land Development Code (LDC), current edition
- LFUCG Zoning Ordinance, Articles 1-23
- KRS Chapter 100 (Kentucky planning and zoning enabling statute)
- KRS 100.111 (definitions), KRS 100.237 (conditional use permits), KRS 100.243 (variances)
- KRS 100.253 (nonconforming uses and structures)
- Local form district design standards and pattern books
