# Client Progress Report

## Purpose

Generate clear, professional progress reports for active civil engineering and landscape architecture projects. Reports communicate project status, completed work, upcoming milestones, budget position, and any issues requiring client action. They serve as both a communication tool and a documentation record that can support invoicing and protect against claims under Kentucky contract law.

## When to Use

- Monthly reporting cycle for active projects (standard for most JEDS contracts)
- Prior to scheduled client meetings or project status calls
- When a significant milestone is reached (design phase completion, permit approval, substantial completion)
- When an issue arises that requires formal client notification (scope change, schedule impact, unforeseen site condition)
- When approaching a contract fee threshold that may trigger an amendment

## Required Inputs

- **Project identification**: Project name, JEDS project number, client name, client project manager
- **Contract data**: Original contract amount, approved amendments, total authorized fee, amount invoiced to date, percentage of fee expended
- **Current phase**: Active design phase or construction administration period
- **Work completed this period**: Specific tasks, deliverables submitted, meetings held, site visits conducted
- **Permit and approval status**: Status of each regulatory submittal (KDOW, local planning, USACE, KY Heritage Council, DOT encroachment)
- **Schedule status**: Current milestone dates vs. original/revised schedule
- **Issues and action items**: Open items requiring client decision, agency comments pending response, unforeseen conditions

## Procedure

1. **Pull project financial data** -- Retrieve current invoicing totals and remaining budget from JEDS accounting. Calculate percent complete by fee and compare to estimated percent complete by scope. Flag any project where fee burn exceeds scope progress by more than 10%.
2. **Document work completed** -- List all work performed during the reporting period with specific deliverables. Use measurable descriptions: "Completed grading plan for 12.4-acre site -- 47 lot subdivision," not "Worked on grading." Reference plan sheet numbers, report sections, or permit application tracking numbers.
3. **Summarize regulatory/permit status** -- Create a permit tracking table with columns: Permit/Approval, Agency, Date Submitted, Status, Expected Decision Date, Action Required. Common KY permits to track:
   - KPDES KYR10 (construction stormwater) -- KDOW, 30-day review
   - Floodplain Development Permit -- local floodplain administrator per KRS 151.290
   - Planning Commission approval -- local jurisdiction (track meeting dates)
   - Sanitary sewer extension -- local utility or DOW per 401 KAR 5:005
   - Water line extension -- DOW Drinking Water Branch per 401 KAR 8:100
   - KYTC encroachment permit -- District office, 30-60 day review
   - Army Corps Nationwide Permit -- Louisville or Huntington District, 45-day review
4. **Assess schedule performance** -- Compare current status to contractual milestones. Identify any slippage and its cause (client review delays, agency review duration, weather impacts on survey, design iteration). Project forward: what is the realistic completion date for each remaining phase?
5. **Identify issues and risks** -- Document any items that could affect scope, schedule, or budget. Categorize as: Client Action Required (decisions, access, information), Agency Dependent (permit review timeline), JEDS Internal (staffing, design challenge), or External (utility conflicts, environmental discovery). For each issue, state the impact if unresolved and a recommended path forward.
6. **Prepare budget summary** -- Table format: Original Contract, Approved Amendments, Total Authorized, Invoiced to Date, Current Period Billing, Remaining Budget, Estimated Cost to Complete. If estimated cost to complete exceeds remaining budget, note the overage amount and recommend a contract amendment with a preliminary scope justification.
7. **Draft action items** -- List every open action item with: description, responsible party (Client, JEDS, Agency, Subconsultant), due date, and status (Open, In Progress, Complete, Overdue). Carry forward unresolved items from prior reports.
8. **Attach key documentation** -- Append relevant items: agency comment letters received, updated schedule, photos from site visits, plan excerpts showing design progress, RFI log (during construction phase).

## Output Format

Structure the report with these sections:
- **Header**: JEDS logo block, project name, project number, report date, reporting period, distribution list
- **Executive Summary**: 3-5 sentences covering overall status, key accomplishments, and critical issues (written so a client executive can read only this section and understand project health)
- **Work Completed This Period**: Bulleted list organized by discipline or phase
- **Permit and Approval Status**: Table format with color-coded status (Green/Yellow/Red or Approved/In Review/Not Submitted)
- **Schedule Summary**: Milestone table or updated Gantt excerpt showing planned vs. actual
- **Budget Summary**: Financial table as described in Procedure step 6
- **Issues and Risks**: Numbered list with impact and recommendation for each
- **Action Items**: Table with columns for Item, Owner, Due Date, Status
- **Next Period Planned Activities**: What JEDS will work on in the upcoming period
- **Attachments**: As applicable

## Quality Checks

- [ ] Financial data reconciles with JEDS accounting records and most recent invoice
- [ ] All active permits and submittals are accounted for with current status
- [ ] Action items from the previous report are carried forward with updated status
- [ ] Schedule dates are realistic and account for known agency review periods in KY
- [ ] Report is written at a level appropriate for client project managers (not overly technical for non-engineers, not oversimplified for technical clients)
- [ ] Any potential scope change or budget overage is flagged proactively, not buried
- [ ] Report date and period are clearly stated to support contract documentation
- [ ] Issues include both the problem and a recommended action -- never flag without a path forward
- [ ] Photos or exhibits are included for any significant site condition or design milestone

## Template Reference

Use JEDS standard progress report template from `templates/progress-report-template.docx` if available. For construction administration phase reports, adapt to include contractor RFI log, submittal log, change order log, and field observation summaries per EJCDC C-700 General Conditions requirements. For KYTC-funded projects, ensure reporting format aligns with KYTC Local Public Agency (LPA) guidelines.
